# Запись на звонок

Сервис записи гостя на встречу с владельцем календаря.

## Термины

**Владелец календаря**:
Человек, чьё доступное время гости бронируют для встреч. В сервисе один заранее заданный владелец календаря.

**Гость**:
Человек, который выбирает тип встречи и записывается на свободное время без регистрации.

**Тип встречи**:
Вариант встречи с названием, описанием и длительностью.
_Не использовать_: Тип события.

**Слот**:
Интервал для встречи, длительность которого совпадает с длительностью выбранного типа встречи.

**Окно записи**:
Период из 14 календарных дней, в пределах которого гость может выбрать время встречи. Окно записи сдвигается с течением
времени.
