# Проверка цепочки генерации API

Проверяет генерацию OpenAPI и SDK из TypeSpec и использование SDK по HTTP.
Транспортная фикстура проверяет GET, POST с JSON-телом, массивы и типизированные ошибки;
серверные интерфейсы проверяются компиляцией. Настоящее приложение проверяет `mise run test:api`.

## Запуск

После установки окружения по корневому README выполните из корня репозитория:

```sh
mise run verify:contract
```
