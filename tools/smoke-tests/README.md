# Дымовые тесты приложения

Пакет проверяет базовую работоспособность собранного приложения: интерфейс в Chromium
и связь с backend через Vite-прокси.

## Текущие проверки

В [app.smoke.test.ts](app.smoke.test.ts) один тест объединяет два сценария:

- **Главная страница** — отображение на широком и узком экранах и доступность навигации.
  Пока разделы записи и управления встречами не реализованы, навигация должна оставаться недоступной
  с пояснениями, как согласовано в [ADR главной страницы](../../docs/adr/0001-home-page.md).
- **Связь с backend** — запрос `/api/health` через Vite-прокси и проверка ответа по сгенерированному OpenAPI.
  Запрос выполняет сам тест; главная страница должна работать без обращений к API.

Визуальное соответствие макету проверяется отдельно: сравнение скриншотов в этот тест не входит.

## Запуск

Из корня репозитория после установки зависимостей:

```sh
mise run test
```

Команда пересобирает frontend и backend. Тест самостоятельно запускает и останавливает серверы
на свободных портах; предварительно запускать приложения в dev-режиме не требуется.

`mise run setup` устанавливает зависимости и Chromium. Для отдельной установки браузера используйте
`mise run setup:browsers`.
