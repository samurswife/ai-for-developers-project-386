# Дымовой тест приложения

Проверяет главную страницу в браузере на широком и узком экранах: содержимое,
недоступную навигацию с пояснениями, отсутствие горизонтального переполнения и
запросов к API со страницы. Отдельно проверяет ответ backend через Vite-прокси
на соответствие OpenAPI.

## Запуск

Из корня репозитория после установки зависимостей:

```sh
mise run test
```

`mise run setup` устанавливает зависимости и Chromium. Для отдельной установки браузера используйте
`mise run setup:browsers`.
