# Документы предметной области

Используем единый предметный контекст сервиса бронирования.

Перед изучением предметной области:

- Прочитай `GLOSSARY.md` в корне репозитория, если он существует.
- Прочитай решения из `docs/adr/`, относящиеся к текущей задаче.

Используй термины словаря в спецификациях, задачах и коде.
При противоречии с ADR явно укажи конфликт и согласуй пересмотр решения.

Отсутствующие документы не препятствуют работе.
Создавай словарь и ADR по мере определения терминов и принятия решений.
