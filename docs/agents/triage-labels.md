# Метки разбора задач

Имена ролей совпадают с метками GitHub:

- `needs-triage` — требуется разбор.
- `needs-info` — требуется дополнительная информация.
- `ready-for-agent` — задача готова к реализации агентом.
- `ready-for-human` — требуется реализация человеком.
- `wontfix` — задача не будет реализована.
