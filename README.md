## О проекте

«Календарь звонков» — упрощённый сервис бронирования времени по мотивам Cal.com.

Владелец календаря создаёт типы встреч и публикует доступное время, а гость выбирает свободный слот и записывается на звонок без регистрации.

В приложении один заранее заданный владелец календаря. Авторизация, личные кабинеты и интеграции с внешними календарями отсутствуют.

## Пользовательский сценарий

1. Владелец календаря создаёт тип встречи, указывая название, описание и длительность.
2. Гость открывает главную страницу и нажимает «Записаться».
3. В каталоге гость выбирает подходящий тип встречи.
4. В календаре на ближайшие 14 дней выбирает дату и свободный слот.
5. Гость вводит имя и электронную почту и подтверждает бронирование.
6. Приложение отображает экран успешной записи с информацией о встрече и возможностью записаться снова.
7. Владелец открывает список предстоящих встреч всех типов и видит созданную запись.

## Основная функциональность

### Для владельца

- Создание типов встреч с названием, описанием и длительностью.
- Просмотр списка предстоящих встреч всех типов.
- Просмотр информации о бронировании: тип встречи, дата, время и данные гостя.

### Для гостя

- Просмотр доступных типов встреч.
- Выбор даты и свободного времени в календаре.
- Бронирование встречи с указанием имени и электронной почты.
- Просмотр подтверждения бронирования.
- Возможность перейти к новой записи.

## Интерфейс

Приложение включает следующие экраны:

- **Главная страница** — описание сервиса и кнопка «Записаться».
- **Каталог встреч** — карточки типов встреч с названием, описанием и длительностью.
- **Выбор даты и времени** — информация о встрече, календарь и список доступных слотов.
- **Форма бронирования** — выбранные дата и время, поля для имени и электронной почты, кнопка подтверждения.
- **Подтверждение записи** — информация об успешном бронировании и возможность записаться снова.
- **Раздел владельца** — создание типов встреч и список предстоящих бронирований.

## Правила бронирования

| Параметр | Значение |
|---|---|
| Часовой пояс | `Europe/Moscow` (UTC+3) |
| Рабочие дни | Понедельник — пятница |
| Рабочие часы | 09:00–18:00 |
| Окно бронирования | 14 календарных дней, включая сегодня |
| Шаг начала слотов | 15 минут |
| Длительность встречи | От 1 до 540 минут |

- Окно бронирования автоматически сдвигается с течением времени.
- Длительность встречи задаётся владельцем при создании типа встречи и может быть любым целым числом минут от 1 до 540.
- Доступные начала встреч рассчитываются с шагом 15 минут.
- Длительность слота соответствует длительности выбранного типа встречи.
- Встреча должна полностью помещаться в рабочие часы владельца.
- Забронировать можно любой свободный слот, начало которого находится в будущем.
- Полное и частичное пересечение встреч запрещено, в том числе для разных типов встреч.
- Следующая встреча может начинаться в момент окончания предыдущей, если это время соответствует шагу начала слотов.
- Правила проверки пересечений действуют и для одновременных запросов.

## API

API разрабатывается на основе TypeSpec-контракта.

Из TypeSpec генерируется OpenAPI-спецификация, на основе которой создаётся типизированный клиентский SDK для frontend-приложения.

Серверные типы и маршруты генерируются, если выбранный фреймворк и инструменты это поддерживают. В противном случае backend реализуется по контракту и проверяется тестами.

## Хранение данных

Данные хранятся в оперативной памяти backend-процесса (in-memory).

При перезапуске сервера созданные типы встреч и бронирования сбрасываются. Постоянное хранение данных не предусмотрено.
